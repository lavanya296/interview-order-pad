# Order pad

A small cafe till, and three problems to solve on it.

```bash
pnpm install
pnpm dev
```

Then open <http://localhost:5173>. The page tells you everything else.

| Folder | What it is |
|---|---|
| `src/` | the till's screen: yours to change |
| `server/` | the API the till talks to: yours to change |
| `guide/` | the page with the instructions: not part of the task |

`pnpm test` runs the tests. `pnpm check` runs the type check, then the tests.

Write what you decide in [NOTES.md](NOTES.md) as you go.
